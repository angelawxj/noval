# 总大纲

## 一句话简介

一个失怙的宗门杂役少年，因意外坠入上古凶地"归墟"遗迹残角，觉醒神秘"道瞳"，从此能鉴万物、观道纹、破生死局，从底层杂役一步步走到执掌归墟秘辛、守护苍生的至强者。

## 五段式主线弧光

| 弧光 | 章节区间（建议，可随创作微调） | 说明 |
|---|---|---|
| 觉醒弧（第一卷） | 约1-30章 | 新手村，练气突破，建立道瞳能力体系 |
| 立足弧（第二卷） | 约31-90章 | 宗门中层站稳，女主线开启，首个反派清算 |
| 出宗弧（第三卷） | 约91-200章 | 归零再登顶，产业帝国扩张，筑基/金丹突破 |
| 揭秘弧（第四卷） | 约201-320章 | 归墟悬念集中释放，跨世界树敌结盟，元婴/化神及以上 |
| 巅峰弧（第五卷） | 约321章起，视连载体量灵活收尾 | 终极对决与感情线收官 |

区间比参考小说同等阶段更紧凑，因不写传承线，篇幅相应收窄，聚焦主角个人成长。

## 世界切换点

"归零再登顶"世界切换建议安排在全书进度约30%（出宗弧开始）和约65%（揭秘弧中段，进入归墟本体舞台前后）附近。

## 成长曲线锚点

- 第5-6章：私下修炼旧口诀首次有气感
- 第14章前后：正式获得外门弟子身份，进入清风峰
- 第一卷末（约第30章）：练气大圆满
- 第二卷末（约第90章）：筑基
- 第三卷末（约第200章）：金丹
- 后续卷随连载体量滚动规划，不提前锁死细节

## 反派憋屈-清算周期

每个反派线埋线约20-40章，再在高潮章节一次性清算（风格规则库038-039）。第一卷反派线：顾云霆/顾崇文。
