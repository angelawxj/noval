# 《归墟道瞳》大纲

> 参考依据见 [00-拆解笔记-符道之祖.md](./00-拆解笔记-符道之祖.md)。以下为定稿版，四项关键决策已与作者确认：境界体系沿用经典九境、单女主不写传承线、精明爽文基调、短章日更(1500-2000字/章)。

## 一句话简介
一个失怙的宗门杂役少年，因意外坠入上古凶地"归墟"遗迹残角，觉醒神秘"道瞳"，从此能鉴万物、观道纹、破生死局，从底层杂役一步步走到执掌归墟秘辛、守护苍生的至强者。

## 核心金手指：道瞳
来源：一位远古陨落至强者残留在归墟中的眼瞳烙印/神识，机缘巧合融入主角右眼（或眉心）。能力分层解锁（随境界突破/顿悟逐步开放新用法，避免一次性开挂）：

1. **鉴物**：辨识丹药/灵材/法器的成色、真伪、年份、隐藏属性 → 对应"捡漏暴富"经济爽点，是全书稳定造钱机器（对标符道之祖的"卖符"）。
2. **观纹**：看见功法、阵法、天地灵气运行的"道纹" → 可加速悟道、临摹功法残篇、破解阵法 → 对应"顿悟/学神"爽点。
3. **照心**：窥见生灵伤势、命门、心念波动一瞬 → 对应"看破诡计/精准反杀"战斗爽点。
4. **归墟回响**：随实力提升，偶尔窥见归墟深处的上古画面/低语 → 逐步揭开"归墟是什么、瞳之主人是谁、归墟为何会吞噬世界"的主线大悬念，作为背景调味线贯穿全书，**不喧宾夺主**（基调已定为精明爽文，悬念服务于爽点节奏，不是主驱动）。

## 主角人设
- 出身：小宗门/边陲村落的孤儿或破落旁支弟子，杂役身份（姓名待定，占位"徐氏"或另拟）。
- 契机：一次护送/救人/坠崖任务中误入归墟遗迹一角，觉醒道瞳。
- 性格底色：沉稳务实、重情义、精明会算计、扮猪吃虎不恃才傲物——靠"鉴物变现"起家，逻辑自洽、脚踏实地，是典型"凡人流"打法。
- 情感线：**单女主**，全书视角贯穿主角本人到底，不涉及子女/后代登场，不写传承暗线（与参考书的多代人传承线明确区分，收窄篇幅、聚焦主角个人成长与感情线）。

## 世界观骨架（多层世界嵌套 + 归零再登顶）
- 第一层：起点宗门（新手村，占位名待定）。
- 第二层：中期舞台——更大的仙域/大陆，宗门林立，拍卖行/工会/排行榜体系齐全。
- 第三层：归墟本体 + 更高维度的仙界/神域（后期揭秘舞台，呼应书名）。
- 境界体系：沿用经典九境——练气 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 炼虚 → 大乘 → 渡劫，不额外发明命名体系，降低设定成本、读者零门槛上手。

## 主线弧光（五段式，因不写传承弧而从参考书六段式收敛）
1. **觉醒弧**（新手村）：杂役少年 → 坠入归墟遗角觉醒道瞳 → 靠鉴物小赚引起宗门注意 → 练气/筑基突破。
2. **立足弧**：加入拍卖/工会体系，结识女主/挚友，遭遇嫉妒型反派打压，逆袭反杀，站稳宗门中层。
3. **出宗弧**：离开新手宗门进入更大世界，经历"从人上人到底层杂役"的再归零，靠道瞳快速重新爬升；家族产业（鉴宝行/拍卖行）在此弧光内扩张为主角个人的产业帝国（无子嗣视角，产业归主角本人打理）。
4. **揭秘弧**：归墟回响逐渐清晰，卷入上古大能遗留的棋局，跨世界树敌/结盟；老对手/老盟友命运在此收尾。
5. **巅峰弧**：登顶最高境界，直面归墟真相与最终反派，完成"守护"或"超脱"结局，与女主感情线收官。
