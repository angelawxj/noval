# 《归墟道瞳》爽点与节奏规划

> 对标基调：精明爽文（参考《符道之祖》）。章节规格：短章日更，1500-2000字/章。

## 爽点清单（六类，逐条给出触发公式）

1. **经济爽点**：道瞳鉴物捡漏 → 低买高卖 → 从摆摊鉴定发展到开鉴宝行 → 灵石数值持续显性增长（每次大额进账在文中明写数字，延续参考书"XX万灵石到手"的爽感写法）。
2. **战斗爽点**：被人轻视/设局 → 道瞳照心看破对方弱点或阴谋 → 精准一击反杀。
3. **智力/学神爽点**：观纹秒解他人卡关多年的阵法/功法残篇，让"学阀"级对手困惑多年的难题被主角轻松破解。
4. **悬念爽点**：归墟回响碎片按"三章一小惊、十章一大惊"的密度释放，逐步拼出归墟真相，作为背景调味线。
5. **装X打脸爽点**：身份/实力反转打脸。**频率上限**：每个大境界弧光内不超过3-4次"高潮级"打脸，其余靠日常小满足点密度撑住，避免审美疲劳。
6. **情感爽点（单女主向）**：知遇之恩回报、并肩作战、雪中送炭，不涉及子嗣线。

## 节奏密度规则

- **每章至少一个小满足点**：延续参考书的高密度节奏，避免注水。
- **五段弧光的章节量建议**（可调整，供作者拍板）：
  | 弧光 | 章节区间建议 | 说明 |
  |---|---|---|
  | 觉醒弧 | 约1-30章 | 新手村，练气突破，建立道瞳能力体系 |
  | 立足弧 | 约31-90章 | 宗门中层站稳，女主线开启，首个反派清算 |
  | 出宗弧 | 约91-200章 | 归零再登顶，产业帝国扩张，筑基/金丹突破 |
  | 揭秘弧 | 约201-320章 | 归墟悬念集中释放，跨世界树敌结盟，元婴/化神及以上 |
  | 巅峰弧 | 约321章起，视连载体量灵活收尾 | 终极对决与感情线收官 |

  （区间比参考书同等阶段略紧凑——因不写传承线，篇幅相应收窄，聚焦主角个人成长。）

- **"归零再登顶"世界切换点**：建议安排在全书进度约30%（出宗弧开始）和约65%（揭秘弧中段，进入归墟本体舞台前后）附近。
- **反派憋屈-清算周期**：每个反派线埋线约20-40章（比参考书的30-50章略紧凑），再在高潮章节一次性清算。
- **排行榜/比武赛制**：从出宗弧（第二层世界）开始引入，作为后期反复调用的长线爽点发生器。
