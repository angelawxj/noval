# 《符道之祖》拆解笔记

> 基于全文1433章章节目录+开篇内容通读整理，作为《归墟道瞳》的结构参考。

## 基本规模
- 全书约1433章（简介写更新到第1668章，本地文件未完结），单章约90行原文（约1500-2000字）。
- 世界分三层嵌套：宗门（绿仙宗）→ 东隅修仙界 → 桑榆大仙界 → 裂星墟（更大舞台），逐层扩展。
- 境界体系：练气(1-12层) → 筑基(初/中/后/大圆满) → 金丹 → 元婴 → 化神 → 合体 → 炼虚 → 大乘 → 渡劫 → (仙)。

## 核心金手指
画符技艺（血脉玉符觉醒 + 上古符道传承）：
- 战力用途：引雷符、剑气符、火雷符等攻击类符箓，后期解锁威力更大的符箓体系。
- 经济用途：卖符赚灵石，是贯穿全书的稳定造钱机器，"低成本高回报"。
- 成长曲线：符箓品阶随境界提升（一品→多品→上古符→天级功法级别的符），保持"手艺变现"贯穿始终，不被战力体系架空。

## 主角人设
放牛娃出身，因救人机缘被带入宗门，从外门杂役起步。**不是靠奇遇堆砌的天命主角**，而是"专业技能变现"型：靠画符这门手艺一步步翻身，逻辑自洽、脚踏实地，读者代入感强。

## 节奏规律（重点）
1. **单章一个小满足点**：几乎每章都有一次赚钱/低买高卖/被小瞧后反杀/解锁新配方等micro-爽点，密度极高。
2. **境界=大arc**：每个大境界对应约80-150章剧情量，境界越高章节量略增（世界观展开、副线变多）。
3. **归零再登顶循环**：每次进入更大世界（宗门→东隅→桑榆→裂星墟），主角都会从"人上人"跌落成底层杂役，再重新爬升。这是全书最大的节奏引擎，反复制造"落差-反杀"爽感而不显重复，因为舞台和对手在升级。
4. **反派憋屈-清算周期**：嫉妒/打压型反派（冷眉、乾元明、周禾硕等）先埋线30-50章制造压抑感，再在高潮章节被一次性反杀，形成周期性节奏点。
5. **家族传承暗线**：中期引入道侣（叶珊瑚）、子嗣（徐承志、徐修凡...），家族产业扩张、后代成才、老一辈坐化，成为贯穿全书的情感暗线，避免单一主角视角疲劳，也让"论资排辈"式装X有了新素材。
6. **排行榜/比武大会机制**：后期大量使用固定赛制（百强榜、金龙榜、总决战）作为"打怪机器"，用可预期的赛制反复制造对手强度递增的爽点，降低编剧压力，也方便长期连载。
7. **数值显性增长**：财富（"XX万灵石到手"）、法宝、功法持续可见地迭代升级，配合世界观扩展，形成清晰的"数值爽感"曲线。

## 可复用到《归墟道瞳》的结构要素
- 一个兼具**战力+经济价值**的独门手艺/能力，作为贯穿全书不掉队的金手指。
- 主角出身底层，靠手艺/能力翻身，而非纯血统/纯奇遇。
- 多层世界嵌套 + 归零再登顶的循环节奏。
- 反派周期性憋屈-清算的支线设计。
- 中后期引入家族传承暗线。
- 中后期引入排行榜/比武赛制作为长线爽点发生器。
